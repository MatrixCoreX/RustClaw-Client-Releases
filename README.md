# RustClaw Client Releases

本仓库只用于发布 RustClaw 桌面端和手机端安装包，不保存应用源码。

安装包请从 [Releases](https://github.com/MatrixCoreX/RustClaw-Client-Releases/releases) 下载：

- Ubuntu Linux x64：DEB
- Windows x64：安装 EXE，以及中文、英文 MSI
- macOS Apple 芯片：DMG 和 app ZIP
- macOS Intel：DMG 和 app ZIP
- Android：兼容 ARM64、ARMv7 和 x86_64 的通用 APK

每个版本都附带 `SHA256SUMS.txt` 和平台验证清单。安装前请核对校验值，并阅读对应版本的签名、公证及测试范围说明。

应用源码继续在 [MatrixCoreX/RustClaw](https://github.com/MatrixCoreX/RustClaw) 维护。本仓库不接受源码提交，也不用于分别维护桌面 UI。
